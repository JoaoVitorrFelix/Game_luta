Jogo de Luta em JavaScript

Este é um jogo de luta desenvolvido com JavaScript, HTML e CSS, no qual você enfrenta um adversário em batalhas rápidas, dinâmicas e cheias de ação.

🎮 Como jogar?

Baixe os arquivos do repositório.

Abra o arquivo index.html em seu navegador.

Divirta-se derrotando seu oponente!
